# 🐍🪜 ربات تلگرامی مار و پله

ربات کامل مار و پله برای تلگرام با:
- تخته‌ی رنگی و زیبا (تولید تصویر با Pillow)
- بازی تکی (کسب سکه)
- چالش دو نفره با شرط‌بندی سکه
- سیستم سکه و امتیاز و جدول برترین‌ها
- جایزه‌ی روزانه
- پنل مدیریت کامل (فقط برای آیدی ادمین)

---

## ۱. ساخت ربات در تلگرام

۱. به [@BotFather](https://t.me/BotFather) پیام بده و با دستور `/newbot` یک ربات بساز.
۲. توکنی که بهت می‌ده رو کپی کن (شبیه `123456:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`).

## ۲. تنظیم فایل .env (فقط برای تست روی سیستم خودت)

فایل `.env.example` رو کپی کن و اسمش رو بذار `.env`، بعد مقادیر رو پر کن:

```
BOT_TOKEN=توکنی که از بات‌فادر گرفتی
ADMIN_IDS=7287316708
DB_PATH=snake_bot.db
```

> اگه چند نفر رو می‌خوای ادمین کنی، آیدی‌هاشون رو با کاما جدا کن:
> `ADMIN_IDS=7287316708,123456789`

## ۳. اجرای محلی (اختیاری، برای تست)

```bash
pip install -r requirements.txt
python bot.py
```

## ۴. دیپلوی روی Railway

### روش ۱: از طریق گیت‌هاب (پیشنهادی)

۱. یک ریپازیتوری جدید توی گیت‌هاب بساز و تمام فایل‌های این پوشه رو داخلش push کن.
2. وارد [railway.app](https://railway.app) شو و لاگین کن.
۳. روی **New Project → Deploy from GitHub repo** بزن و ریپازیتوری رو انتخاب کن.
۴. بعد از ساخته شدن پروژه، برو به تب **Variables** و این متغیرها رو اضافه کن:
   - `BOT_TOKEN` = توکن ربات
   - `ADMIN_IDS` = `7287316708`
5. Railway به‌خاطر وجود فایل `Procfile` و `railway.json` خودش تشخیص می‌ده که باید
   `python bot.py` رو اجرا کنه (Nixpacks به‌صورت خودکار `requirements.txt` رو نصب می‌کنه).
6. صبر کن دیپلوی تموم بشه، بعد از تب **Deployments** لاگ‌ها رو چک کن؛ باید پیام
   «دیتابیس آماده شد. ربات در حال اجراست...» رو ببینی.

### روش ۲: از طریق Railway CLI

```bash
npm i -g @railway/cli
railway login
cd snake_ladder_bot
railway init
railway up
railway variables set BOT_TOKEN=توکن_ربات
railway variables set ADMIN_IDS=7287316708
```

> ⚠️ نکته مهم: چون ربات با **Long Polling** کار می‌کنه (نه Webhook)، نیازی به دامنه یا
> پورت باز نیست؛ فقط باید سرویس همیشه روشن (`worker`) باشه، که با تنظیمات فعلی
> (`Procfile` روی `worker`) همینه.

### نکته درباره‌ی دیتابیس

دیتابیس SQLite به‌صورت یک فایل (`snake_bot.db`) کنار پروژه ساخته می‌شه. توی Railway،
فایل‌سیستم بین دیپلوی‌های جدید ممکنه ریست بشه؛ اگه می‌خوای داده‌ها (سکه‌ها، کاربران)
همیشه بمونن، از بخش **Volumes** ریلوی یک Volume به مسیر پروژه وصل کن و متغیر
`DB_PATH` رو به مسیر داخل همون Volume تنظیم کن (مثلاً `/data/snake_bot.db`).

## ۵. راهنمای استفاده از ربات

- `/start` — شروع و نمایش منوی اصلی
- 🎮 **بازی تکی** — با پرداخت هزینه‌ی ورود بازی می‌کنی، اگه به خونه‌ی ۱۰۰ برسی جایزه می‌گیری
- ⚔️ **چالش با دوست** — روی پیام دوستت ریپلای کن و بنویس: `/pvp 50` (عدد = مبلغ شرط)
  یا از فرمت `/pvp @username 50` استفاده کن
- 💰 **موجودی من** — نمایش سکه، برد‌ها و تعداد بازی‌ها
- 🏆 **برترین‌ها** — جدول ۱۰ بازیکن برتر
- 🎁 **جایزه روزانه** — هر ۲۴ ساعت یک‌بار

## ۶. پنل مدیریت (فقط آیدی 7287316708)

با دستور `/admin` یا دکمه‌ی «🛠 پنل مدیریت» در منوی اصلی باز می‌شه:

- 📊 آمار کلی ربات (تعداد کاربر، مجموع سکه‌ها، تعداد بازی‌ها و ...)
- 💰 افزودن یا کم‌کردن سکه‌ی هر کاربر (با آیدی عددی یا یوزرنیم)
- 🚫 مسدود / رفع مسدودیت کاربر
- 📢 ارسال پیام همگانی به همه‌ی کاربران ربات
- ⚙️ تغییر تنظیمات اقتصاد بازی (سکه شروع، جایزه روزانه، هزینه‌ی بازی تکی،
  جایزه‌ی بازی تکی، شرط پیش‌فرض بازی دو نفره)

## ساختار فایل‌ها

```
snake_ladder_bot/
├── bot.py              # نقطه‌ی شروع ربات
├── config.py            # تنظیمات، خانه‌های مار و نردبان
├── database.py          # تمام کوئری‌های دیتابیس (aiosqlite)
├── game_logic.py        # منطق تاس و حرکت مهره
├── board_image.py       # تولید تصویر تخته با Pillow
├── keyboards.py         # دکمه‌های شیشه‌ای (inline keyboard)
├── handlers/
│   ├── user.py           # /start، منو، پروفایل، جایزه روزانه، برترین‌ها
│   ├── game.py           # بازی تکی و دو نفره
│   └── admin.py          # پنل مدیریت
├── requirements.txt
├── Procfile
├── railway.json
└── .env.example
```

## نکته درباره‌ی امنیت شرط‌بندی

سکه‌های این ربات صرفاً داخل خودِ ربات (درون‌بازی) هستن و هیچ ارزش یا تبدیل به
پول واقعی ندارن؛ صرفاً برای سرگرمی و رقابت بین کاربرا طراحی شده.
